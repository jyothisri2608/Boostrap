ESCAPE ISLANDS - HTML + CSS + BOOTSTRAP ONLY

Files:
- island.html
- style.css

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open island.html with Live Server, or double-click island.html.

Important:
- This project uses Bootstrap CSS only.
- There is no JavaScript file, no script tag and no Bootstrap JavaScript.
- The navigation menu is made with HTML checkbox + CSS.
- Island detail sections use the native HTML details/summary elements.
- The contact form is a basic HTML mailto form. Replace your-email@example.com with your own email address if you want it to open an email application.
- An actual online enquiry system needs a backend or form service.
- Internet is needed to load Bootstrap CSS and the online photos.
